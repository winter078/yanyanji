# 音乐 / 倒数日组件 2×2 · Design Brief

## 路由与产物

- 生产轨道：pure-coding。两个组件都由 HTML/CSS 原生文字、几何与内嵌矢量构成，封面用 CSS 抽象色块表达，不生成图片素材。
- 品类：未命中现有垂类 Ref，按 generic-fallback 处理；原因是小型桌面 UI 组件，不属于海报、详情页、简历、信息图等既有品类。
- 交付：先交付一张并排预览图，确认视觉方向后再接入实际桌面代码。
- 画幅：预览板 1200 × 900 px；实际组件按 2×2 网格约 182 × 182 px 的正方形设计，预览按 320 × 320 放大展示。
- 不接 API：音乐播放、进度、倒数日日期都用静态示例，不伪造真实用户数据。

## 主题与核心对象

- 主题：给“我的小手机”增加两个常驻桌面组件：音乐播放和倒数日。
- 核心对象：音乐组件、倒数日组件；无商品、无人物、无外部服务。
- 受众：使用者本人；组件要安静，不能比桌面照片更抢眼。

## 内容与层级

### 音乐组件

- 布局参考：用户提供的第二张音乐组件截图，只继承空间关系与控件结构，不继承它的浅灰配色、黑白封面或字体。
- 继承机制：方形专辑图在左上；右上是一颗波形圆钮；专辑图下方居中放歌名；歌名下方是一排小控件；最底部居中放上一首 / 暂停 / 下一首。整体按“封面 → 歌名 → 小控件 → 主播放键”的顺序阅读。
- 可见文字：
  - 歌名：`晚风轻轻吹过`（示例）
  - 歌词：`让晚风替我拥抱你` / `在每一个安静的夜里`（示例）
- 第一焦点：方形封面。
- 第二层：歌名与两行歌词。
- 第三层：底部主播放键。
- 控件：底部三颗主控件；原参考图的小控件行在 2×2 内会让歌名与歌词之间留下空洞，改为两行歌词后移除。接桌面时再接真实播放、暂停、切歌与进度。
- 封面：深色低饱和抽象画面，暖褐与橄榄灰；不使用真实专辑封面、不写真实歌手名。
- 不复刻参考图的浅灰底、黑白硬边和字体，改用当前烟灰玻璃与暖灰文字系统。

### 倒数日组件

- 布局参考：用户提供的第二张双人头像组件截图，只继承双圆头像、下方表情署名和底部胶囊控件的关系。
- 继承机制：两个圆形头像并排在上方；每个头像下方一行小表情作为署名；底部是一条横向胶囊，放日期与剩余天数。
- 头像：两张可替换的圆形图片；预览用示例图占位，接桌面后由用户从相册选择，点击头像可换图。
- 底部胶囊：显示 `11月20日 · 星期五 · 还有 8 天`（示例）；接桌面后点击胶囊可从“小手机”里的倒数日列表选择目标日期，并同步事件与剩余天数。
- 第一焦点：两张圆形头像。
- 第二层：底部日期胶囊。
- 第三层：头像下的表情署名。
- 不伪造真实事件；接入时由用户填写或从小手机倒数日里选择。

## 视觉主张

- 关键词：暗色、低亮度、烟灰玻璃、安静、iOS 桌面感。
- 容器：圆角矩形玻璃卡，单一烟灰玻璃色，无硬描边、无第二种玻璃颜色、不使用紫色。
- 材质：轻磨砂与背景模糊，能看见桌面光影但不完全融进去；靠内高光和柔和阴影建立体积。
- 文字：系统无衬线；音乐组件歌名中等字重，封面承担色彩；倒数日组件头像最抢眼，日期胶囊退后。
- 装饰：音乐封面用抽象色块与柔和光晕，右上波形圆钮做音量暗示；倒数日不加多余装饰，留白承托两张头像。
- 禁止：高亮白底、彩色渐变、霓虹、硬边框、假数据、真实品牌/专辑封面。

## 决策优先级

1. 用户已确认的暗色玻璃基调。
2. 2×2 比例与桌面可读性。
3. 单一玻璃材质、无硬边框。
4. 音乐封面与倒数日数字各自形成第一焦点。
5. 控件和辅助信息不抢主层级。

## 验收重点

- 两张卡在 1:1 的 2×2 比例内完整容纳内容，不拥挤、不裁切。
- 音乐组件第一眼看到封面，第二眼看到歌名，底部主控件清楚可点。
- 倒数日组件第一眼看到两张圆头像，底部日期胶囊完整可读。
- 玻璃卡无硬边框也成立，放在深色背景上能看出是独立组件。
- 缩到实际 2×2 尺寸（约 182 × 182 px）时，歌名、日期与剩余天数仍清楚，头像不变形。
- 不出现真实品牌、真实专辑封面或伪造的用户数据。
- 音乐组件若在 2×2 内显得过挤，可提出改为 4×2 的后续方案；本次预览仍按 2×2。
